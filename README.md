Student Management System

A Python-based student management application that helps manage student information, academic results, and attendance records.

Features:
1.Add students
2.View all students
3.Search students by name
4.Update student information
5.Delete students
6.Add student marks
7.Calculate total marks
8.Calculate average marks
9.Assign grades
10.View student results
11.Add attendance records
12.Calculate attendance percentage
13.View student attendance
14.Store data using SQLite
15.Data remains available after restarting the application

Technologies Used:-
1.Python
2.SQLite
3.Git
4.GitHub

Project Structure:-

Student-management
│
├── main.py

students.db is a local database file and is excluded from Git tracking.

How to Run
Clone the repository.
Open the project folder in VS Code.
Run:
python main.py

The SQLite database will be created automatically when the application starts.

    Data Persistence

Student information, marks, and attendance records are stored in a local SQLite database.

The data remains available even after closing and restarting the application.
